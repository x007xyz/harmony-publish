## 文案生成模板（根据 App 真实功能自动生成）

- **应用名称**：`主功能名：一句话定位`（≤30 字符；与包内 `EntryAbility_label` 一致，
  不一致时改包内 label 为长名）
- **一句话简介**：≤17 字符，`主功能 + 关键动词`（如「管理配方，按份数自动换算配料用量」）
- **应用介绍**（3-5 句，从功能代码中提取真实能力）：
  1. 第一句：应用是什么 + 核心场景
  2. 第二句起：2-3 个主要功能（从页面/模型/工具类代码提取，逐条列出）
  3. 本地化承诺：数据本地处理、无需注册、不联网（依据 pubspec 无网络依赖可证实）
  4. 商业模式：一次性买断、无内购无广告（若属实）
- **更新说明**：`首个版本：支持…`（功能清单，来自实际功能）
- **审核备注**：无需登录、无账号/云端；审核路径（进入哪个页面做什么操作）；
  数据本地处理、不申请敏感权限
- **截图内容**：每张对应一个主页面（首页/列表页/计算器/设置），按实际 UI 截取

## 发布前预生成清单（下拉项提前确定，不在页面确认）

1. 分类 + 标签（主标签）→ UI 显示名写入 `category`/`tag`，官方确认的数字 ID 写入 `harmonyChildType`/`kindMainTag`
2. 分级问卷答案 → 根据真实功能填写；将官方反馈交给 `rating-draft`
3. 审核备注文案 → 写入 `projects.json` 的 `remarks`
4. 包名/版本 → 写入 `projects.json` 的 `packageName`/`packageVersion`（prepare-version-basic 自动读取）
5. 应用名称/简介/描述/更新说明 → 写入 `release/appgallery.metadata.json`
6. 截图（3-5 张 1080x1920）→ 绝对路径写入 metadata.screenshots（来源优先级：
   `design/screenshots/final/` 已有 → Golden（`test/goldens/`）/ e2e（`qa_shots/e2e/`）
   测试截图 → image-gen 以 App 截图为参考生成，详见 SKILL.md 第 4 步）
